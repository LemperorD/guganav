# IMU 六面标定

这个工具用六面静止法标定加速度计的零偏、标度因子与交叉耦合，并给出陀螺零偏。
它不依赖雷达，也不需要转台，把传感器分别按六个朝向放在水平面上采集数据即可。

## 能标什么，不能标什么

能标定的量：

- 加速度计零偏 b，单位 m/s^2。
- 加速度计标度因子与交叉耦合矩阵 M，无单位。
- 陀螺零偏 b_g，单位 rad/s。

不能标定的量：

- 陀螺标度因数。六面静止法没有角速度激励，这一项需要转台或已知角速度。
- 加速度计与陀螺之间的轴间不对准。这一项需要专门的转台测试。
- 雷达与 IMU 的外参和时间偏移。这一项需要连续运动数据，与本工具无关。

## 测量模型

加速度计按下面的模型描述：

    a_meas = M @ a_true + b

其中 a_meas 是传感器读数，a_true 是真实比力，M 是 3x3 的标度与交叉耦合矩阵，
b 是零偏。

当某个坐标轴竖直朝上时，a_true = +g e_axis；朝下时 a_true = -g e_axis。
六个朝向一共给出 18 个方程，M 与 b 共 12 个未知量，按行做最小二乘即可求解。

标定完成后，用下面的式子把读数修正为真实比力：

    a_true = M^-1 (a_meas - b)

`solve` 输出的 JSON 里已经保存了 `M_inv` 与 `bias`，可以直接使用。

## 依赖

- Python 3.10，numpy。
- 整条链路不依赖 ROS。采集由 `scripts/imu_lidar` 完成，它直接从 MID-360 读取 IMU。

## 操作步骤

第一步，把传感器固定在可以翻转的夹具或平台上，接好线，上电预热五分钟以上。
MEMS 加速度计的零偏随温度漂移，预热不充分会让零偏估计随采集顺序变化。

第二步，用 MID-360 读取工具采集：

```bash
bash scripts/imu_lidar/build.sh
scripts/imu_lidar/imu_lidar --six-face --duration 5 \
    --out /tmp/imu_six_face.csv
```

程序会依次提示六个朝向，每个朝向按回车后先等角速度平稳，再采集指定时长。
采集期间不要触碰传感器与线缆。网络配置与用法的说明见
`scripts/imu_lidar/README.md`。

第三步，求解：

```bash
python3 scripts/imu_calib/imu_calib.py solve --csv /tmp/imu_six_face.csv \
    --out /tmp/imu_calibration.json
```

第四步，验证。用标定结果修正同一份数据，检查模长是否收敛到 g：

```bash
python3 scripts/imu_calib/imu_calib.py apply --csv /tmp/imu_six_face.csv \
    --calib /tmp/imu_calibration.json --out /tmp/imu_corrected.csv
```

没有硬件时可以先用合成数据验证算法：

```bash
python3 scripts/imu_calib/imu_calib.py selftest
```

## 输入数据格式

CSV 至少包含下面这些列，列顺序不限：

| 列名 | 含义 |
| --- | --- |
| `t` | 时间戳，单位秒，可省略 |
| `ax` `ay` `az` | 加速度，单位 g 或 m/s^2 |
| `wx` `wy` `wz` | 角速度，单位 rad/s |
| `face` | 朝向，取值为 `+x` `-x` `+y` `-y` `+z` `-z` |

`scripts/imu_lidar` 写出的 CSV 就符合这个格式。也可以自己整理数据，例如把
现有 bag 分段导出后补上 `face` 列。

## 单位处理

加速度单位按六面读数的模长中位数自动判断：接近 1 时按 g 处理，接近 9.8 时按
m/s^2 处理。实车 Livox 驱动输出的加速度是 g，仿真输出的是 m/s^2，两种情况都
能自动识别。判断失败时用 `--unit g` 或 `--unit mps2` 显式指定。

标定结果统一以 m/s^2 为基准。`apply` 会把输入换算到 m/s^2、修正后再换回输入
单位，所以输出的 CSV 与原始数据使用同一个单位。

## 结果怎么读

`format_report` 打印的内容里，重点看三处：

- 逐面残差。校准后模长误差应在 0.05 m/s^2 量级。超过 0.1 m/s^2 说明安装面
  不够水平，或者采集期间有晃动。
- 标度误差。MEMS 加速度计的标度误差通常在百分之几。超过 5% 会提示检查。
- 各面主轴读数。符号与预期相反时程序直接报错，说明朝向放反或轴向标记不一致。

`--model diag` 只解三个标度因子与零偏，等价于教材里常见的成对公式：

    b_i = (a_i(+) + a_i(-)) / 2
    s_i = (a_i(+) - a_i(-)) / (2 g)

`--model full` 额外解出交叉耦合项，是默认值。六个朝向对 12 个未知量是恰好可解
的，交叉耦合项的估计精度受安装倾斜影响，读数时把它当作量级参考。

## 已知限制

- 安装倾斜会被交叉耦合项吸收一部分。每个面倾斜 1 度，会让另外两个轴出现约
  0.017 g 的分量，进而污染交叉耦合的估计，所以夹具的水平度直接影响这一项。
- 六个朝向不足以估计加速度计的非线性，量程边缘的误差不会被发现。
- 采集期间的温度变化会改变零偏，长时间采集建议分批做，观察零偏是否稳定。
